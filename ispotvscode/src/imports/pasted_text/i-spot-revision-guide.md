현재 I-SPOT 웹페이지의 기존 디자인, 레이아웃, 컬러 시스템, 사이드바 구조, 컴포넌트 스타일을 최대한 유지하면서 아래 요구사항만 반영하여 수정한다.

중요:
- 기존 페이지를 처음부터 새로 디자인하지 말 것.
- 기존 I-SPOT의 네이비 사이드바, 흰색/연회색 콘텐츠 영역, 블루 포인트 컬러를 유지할 것.
- 기존 페이지의 기능과 화면 이동을 임의로 삭제하지 말 것.
- 아래에서 명시하지 않은 텍스트, 레이아웃, 컴포넌트는 가능한 한 유지할 것.
- AI가 아동학대 여부, 위험도, 개입 우선순위, 종결 여부를 최종 판단하는 것처럼 표현하지 말 것.
- AI는 근거·참고정보·확인 필요 항목을 제시하는 보조 도구이며 최종 확인 및 판단은 상담사가 수행하는 구조로 통일할 것.
- 새로운 백엔드 API나 실제 데이터 연동 기능을 임의로 만들지 말 것.
- 기존 mock data가 필요한 경우 현재 구조를 유지하여 화면 동작만 표현할 것.

- 참고 정보

최종 개입 영역 및 계획은 상담사가 직접 선택하거나 작성한다.


필요한 경우 다음 구조를 사용한다.

문제/확인 영역
→ 관련 근거
→ 상담사 확인 상태
→ 상담사 지정 개입 계획

6. 종결·가정복귀 검토 화면 수정
==================================================

기존의

"종결 가능성"

표현을 전부

"종결 검토 항목 확인 현황"

으로 변경한다.


종결 여부를 AI가 결정하거나
높음/중간/낮음으로 평가하지 않는다.

종결 화면의 각 검토 항목에 다음 선택값을 제공한다.

[근거 확인]
[정보 부족]
[해당 없음]
[추가 상담 필요]


각 항목에는 다음 정보를 함께 표시할 수 있도록 한다.

- 검토 항목
- 관련 근거
- 근거 출처
- 상담 회차
- 원문 발화 또는 기록
- 상담사 선택 상태
- 상담사 메모


상단에는 전체 검토 현황을 표시한다.

예:

필수 검토 항목 8개
확인 완료 5개
정보 부족 2개
추가 상담 필요 1개


중요:
모든 필수 검토 항목을 상담사가 직접 검토하기 전까지

"종결 검토 자료 제출"

버튼을 disabled 상태로 유지한다.


활성화 조건:

모든 필수 항목이 다음 중 하나로 명시적으로 선택된 경우

- 근거 확인
- 정보 부족
- 해당 없음
- 추가 상담 필요

즉, 선택되지 않은 필수 항목이 하나라도 존재하면 제출 불가.


비활성 버튼 주변에는 간단히 다음 안내를 표시한다.

"필수 검토 항목을 모두 확인해야 제출할 수 있습니다."

표현을

"회차별 근거 신호 변화"

AI 결과 = 확정 판단 X
AI 결과 = 상담사 검토를 위한 참고자료 O

최종 내용은 담당 상담사의 검토·확인 후 확정됩니다."

해당 데이터가 어떤 기준인지 반드시 명시한다.

9. 미확인 항목 처리 정책
==================================================

화면별로 미확인 항목 처리 방식이 다르므로 다음 정책을 UI 동작에 반영한다.


상담일지 작성:
미확인 항목이 존재해도 진행 가능.
단, 상담사가 사유를 기록한 뒤 진행한다.


AI 결과 검토:
모든 항목을 반드시 즉시 완료할 필요는 없다.
"확인 필요" 상태로 저장할 수 있다.


종결 검토 제출:
필수 검토 항목 중 선택되지 않은 항목이 하나라도 존재하면 제출할 수 없다.


관리자 검토:
미확인 필수 항목이 존재하는 문서는 관리자가

"보완 요청"

할 수 있다.

- 기존 네이비 사이드바 유지
- 기존 헤더 유지
- 기존 카드/테이블 스타일 유지
- 기존 typography hierarchy 유지
- 기존 spacing 최대한 유지
- 불필요한 아이콘 추가 금지
- 이모지 사용 금지
- 과도한 색상 추가 금지
- 위험/주의가 필요한 상태에만 제한적으로 red/amber 사용
- 기본 액션은 기존 blue 계열 유지
- 상태는 색상만으로 구분하지 말고 반드시 텍스트를 함께 표시
- 전문 상담사가 사용하는 업무 시스템이므로 설명 문구를 과도하게 늘리지 말 것
- 한 화면에 불필요한 대형 카드나 장식 요소를 추가하지 말 것


==================================================
13. 최종 확인
==================================================

수정 완료 후 전체 프로젝트에서 다음 기존 표현이 AI 판단 의미로 남아 있지 않은지 확인한다.

- 위험 지표 감지
- 위험 수준
- 개입 우선순위
- 종결 가능성
- AI 승인 완료
- 고위험 / 중위험 / 저위험
- 위험도 점수
- 낮음으로 평가
- 위험도 점수 변화
- AI 위험도 추이 그래프
- 개입 영역 우선순위


단,
관리자 문서 승인 workflow의 실제 "승인 완료"는 변경하지 않는다.

또한 신규 화면
DOCUMENT_WRITE_01
"상담일지 AI 초안 수정"
화면이 정상적으로 접근 가능하도록 기존 "문서 작성" 또는 관련 상담 업무 흐름과 연결한다.

최종 업무 흐름은 다음 의미가 명확하게 드러나도록 한다.

상담 자료 등록
→ 텍스트 처리
→ 상담 내용 검수
→ AI 보조 분석
→ 근거 및 미확인 항목 상담사 검토
→ 상담일지 AI 초안
→ 상담사 수정·확정
→ 사례관리
→ 종결·가정복귀 검토

AI는 최종 의사결정자가 아니며,
모든 중요한 판단과 기록의 최종 주체는 상담사이다.
