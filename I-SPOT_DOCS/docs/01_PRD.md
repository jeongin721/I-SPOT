# 01_PRD.md — Product Requirements Document

## 1. 서비스 정의

**I-SPOT**은 아동 상담 음성·텍스트를 AI로 분석하여 위험 관련 발화와 학대유형별 참고 신호를 근거와 함께 제공하고, 상담 기록 초안을 자동 생성하여 상담사의 검수와 판단을 지원하는 서비스다.

## 2. 사용자

### Primary
- 아동 상담사
- 사회복지사
- 사례관리 담당자

### 원칙
AI는 판단 보조만 수행한다.
학대 여부, 사례 종결, 가정복귀 여부 등 최종 결정은 상담사·전문가가 수행한다.

## 3. 핵심 문제

1. 상담 중 메모·기록 때문에 아동과의 대화 집중이 떨어질 수 있다.
2. 긴 상담에서 위험 관련 발화와 간접 신호를 다시 찾는 데 시간이 든다.
3. 상담 종료 후 상담일지·사정기록지를 반복 작성해야 한다.
4. 회차가 늘어날수록 이전 상담과 현재 상태를 비교하기 어렵다.

## 4. MVP 핵심 Flow

```text
사례 선택
→ 상담 회차 생성
→ 음성 녹음/업로드
→ STT 및 화자 구분
→ STT 검수
→ AI 분석
→ 상담 요약/문서 초안
→ 상담사 수정
→ 승인
→ 저장
```

## 5. Must Have

- Case 등록/조회
- Session 생성/조회
- 상담 음성 녹음 또는 업로드
- STT
- 상담사/아동 화자 구분
- STT 수정 및 확정
- 위험 관련 발화 탐지
- 신체/정서/성/방임 관련 신호
- Risk Factor 추출
- 근거 문장 제공
- 상담 요약
- 상담일지 초안
- 사정기록지 초안
- 상담사 수정·승인
- Case/Session 기준 저장

## 6. Should Have

- 위험 문장 하이라이트
- 음성 timestamp와 근거 연결
- 이전 회차 비교
- 반복/신규 Risk Factor
- 회차별 위험 변화
- 사례회의용 요약

## 7. Later

- 과거 중대사건 RAG
- 사례관리 방향 추천
- 종결/가정복귀 검토 지원
- 외부기관 보고서
- 기관 시스템 연계

Must Have가 안정적으로 동작하기 전에는 Later 기능을 우선 구현하지 않는다.

## 8. 핵심 성공 기준

- 상담 후 기록 작성시간 감소
- 위험 관련 주요 발화 누락 최소화
- 상담사가 근거 발화를 쉽게 확인 가능
- AI 초안을 상담사가 수정·승인 가능
- 상담 종사자가 핵심 Flow를 어렵지 않게 수행 가능

## 9. 범위 판단 규칙

새 기능을 요청받으면 다음으로 분류한다.

```text
MVP 필수인가?
→ 기존 Flow를 완성하는가?
→ 다른 파트 Contract 변경이 필요한가?
→ Later로 미뤄도 되는가?
```

기획에 없는 기능을 AI가 임의로 MVP에 추가하지 않는다.
