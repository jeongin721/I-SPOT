## 파일 형식 (`*.dc.html`)

한 파일이 한 화면입니다. 디자인 도구 전용 형식이라 브라우저에서 바로 열면 그대로 보이지 않습니다.

| 부분 | 내용 |
| --- | --- |
| `<x-dc>` … `</x-dc>` | 화면 마크업. `{{ 이름 }}` 은 값 자리, `<sc-for list as>` 는 반복, `<sc-if value>` 는 조건 |
| `<helmet><style>` | 화면 CSS. 기본 → 화면별 → 부분 뉴모피즘 → 다크 모드 → 화면별 추가 → 반응형 → 모서리 정리(각진 UI) → 사이드바 고정 · 분석 알림 등 공통 추가 |
| `<script type="text/x-dc">` | `class Component extends DCLogic` — `state` 와 `renderValsBase()`(예시 데이터 · 버튼 동작). `renderVals()` 는 다크 모드 · 분석 알림 등 공통 값을 덧붙이는 감싸개 |

`counselor-web/src/dc.js` 의 `DCLogic` · `useDC` 가 같은 구조(state + renderVals)를 React 에서 쓰려고 만든 어댑터입니다. 화면을 옮길 때는 `renderValsBase()` 의 예시 데이터를 훅 결과로 바꾸면 됩니다.

### ⑨ 모바일 앱 (`/app` · 설치형 PWA, 360×800 기준)

웹과 화면 · 기능이 완전히 다른 현장용 앱입니다. 같은 프로젝트 안에서 주소를 `/app` 아래로 나누고(설치 시 시작 주소 `/app` = AppHome), 설치한 앱으로 열리면 항상 `/app` 으로 보내는 구성을 권장합니다. 로그인 · 데이터 · API 는 웹과 공유합니다.

## 화면 사이에 넘기는 값

디자인에서는 화면끼리 값을 넘기려고 브라우저 저장소(localStorage · sessionStorage)를 썼습니다. 실제 구현에서는 `counselor-web` 의 규칙대로 **주소 쿼리(`case` · `session`)나 상태 관리, 서버 상태로 바꿔야 합니다.**

| 키 | 넣는 곳 → 읽는 곳 | 뜻 |
| --- | --- | --- |
| `ispot-theme` | 모든 화면 | 다크 모드 (`dark` / `light`) |
| `ispot-back` | 각 화면 → UploadModal · CaseRegister | 팝업을 닫으면 돌아갈 화면 |
| `ispot-ses` | CaseHistory → SessionDetail | 고른 회차 번호 |
| `ispot-form` | CaseDocs · CaseDetail → CaseForm | 열 서식 (A 사정기록지 · B 점검표 · C 위험수준 척도 · D 가족관계 척도) |
| `ispot-stt` | ChildDetail · CaseApp → SttReview | 근거 원문 위치(시간). STT 화면에서 그 발화로 스크롤 · 강조 |
| `ispot-child` | ChildDetail · CaseApp → ChildAnswers | 과거 답변 기록을 볼 아이(사례 ID) |
| `ispot-job` | UploadModal · CaseDetail(녹음 저장) → 모든 화면 | 분석 작업 `{ t: 시작 시각, name: 파일 이름 }`. 디자인에서는 시작 뒤 8초를 '분석 중', 이어서 3초를 '분석 완료' 로 흉내 냄 |
| `ispot-intake` | Schedule(최초접수 저장) → 상담사 화면 알림 | 최초접수 기록 `[{ id, child, y, m, d, time, place, imp, done: { 3, 7, 30 } }]`. 법정 기한 일정 · 알림은 여기서 계산 |
| `ispot-noti-read` | 알림 → 알림 | 읽은 알림 ID 목록 |
| `ispot-sched-go` | 알림 → Schedule | 알림을 눌렀을 때 열 날짜 |
| `ispot-staff` | AdminAccounts · AdminCases → AdminStaffDetail | 고른 상담사 정보 |
| `ispot-app-q` | AppRecord · AppUpload → 앱 화면 전체 | 앱 업로드 목록(완료 · 올리는 중 · 실패) |
| `ispot-app-memo` | AppMemo | 앱 메모 |
| `ispot-app-rec` | AppSchedule · AppBrief · AppCases → AppRecord | 녹음 화면에 미리 고를 아이 |
| `ispot-app-notice` | AppHome | 읽은 사내 공지 ID |
| `ispot-app-set` | AppSettings | 앱 알림 · Wi-Fi에서만 올리기 설정 |
