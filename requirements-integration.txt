# 통합 트리(backend + ai/ + stt/) 를 한 venv 에서 실행하기 위한 추가 의존성.
#
# backend/requirements.txt 는 Backend 단독 실행 의존성이므로 수정하지 않는다.
# 팀 A(stt/) / 팀 B(ai/) 코드를 실제로 import 해서 쓸 때만 아래를 추가 설치한다.
#
#   . backend/.venv/bin/activate
#   pip install -r backend/requirements-dev.txt
#   pip install -r requirements-integration.txt
#
# 주의: STT 화자분리(diarization) 옵션인 pyannote-audio/torch 는 포함하지 않는다.
#       stt/ispot_stt.py 의 diarization 은 I_SPOT_SPEAKER_DIARIZATION_PROVIDER=pyannote
#       일 때만 필요하고, 기본값(mock)/deepgram 경로에서는 쓰이지 않는다.
#
# ------------------------------------------------------------------
# 최상위 requirements.txt 와 헷갈리지 말 것. 용도가 다르다.
#
#   requirements.txt              최상위 main.py 실행용 (팀 A 인계 대상).
#                                 학대 모델을 직접 돌리므로 torch/transformers 를 포함한다.
#                                 절차는 HANDOFF_STT.md §11 참조.
#
#   requirements-integration.txt  이 파일. Backend 가 stt/·ai/ 를 import 해서
#                                 쓰는 경로만 커버한다.
#
# 둘 다 최상위에 있지만 서로를 대체하지 않는다.
# ------------------------------------------------------------------
