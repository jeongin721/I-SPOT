# 세부 위험신호 판정 기준 v1 (판례집 기반)

2차 세부 위험신호 14종을 사람이 판정할 때 쓰는 기준이다. 기준의 출처는
「2020-2022 아동학대사건 판례연구」(아주대학교 법학전문대학원, 이하 **판례집**)이며,
판례집에 근거가 없는 항목은 "우리 분류 정의"로 따로 표시했다.
**이 문서는 전문가 검수를 거치지 않은 초안이다.** 검수자는 근거 열의 판례집 위치를
찾아 대조할 수 있다.

인용 표기: `일반론 xx쪽`은 판례집 앞부분 '연구의 개요'(로마자 쪽수).
`목차 Ⅱ-9`는 **제1부(부모·친족에 의한 학대)** 목차의 학대유형(Ⅰ 신체, Ⅱ 정서,
Ⅲ 유기·방임)과 판례 번호이고, `2부 Ⅱ-9`는 **제2부(보육·교육시설 등)** 목차이다.
성적 학대 판례는 제2부에만 있어서 `2부 Ⅲ-x`로 표기한다.

## 공통 원칙

| # | 원칙 | 근거 |
|---|---|---|
| G1 | 아동이 **구체적으로 진술한 행위**만 근거로 삼는다. 상담사 질문에 들어 있는 행위를 아동이 확인하지 않았으면 근거가 아니다(예: "만지거나 보여달라고 했나요?"에 "네"만 답하면 어느 행위인지 특정 불가). | 일반론 x쪽(진술의 구체성·일관성, 질문자에 의한 피암시성) |
| G2 | **훈육의 경계**: ① 합리적 범위 안에서 가장 적절하다고 생각하는 지도 방법이고 ② 계속적인 훈육의 일환이면 학대가 아니다. 청소 당번, "방에 가서 생각하고 와" 같은 정도는 학대로 보지 않는다. | 일반론 vii쪽(대법원 2020.1.16. 선고 2017도12742) |
| G3 | **중복 인정**: 한 진술이 여러 세부유형에 동시에 해당할 수 있다. 각 유형마다 **독립된 근거**가 있어야 한다. 신체학대와 정서학대는 별도 성립을 인정한 판결이 많다. | 일반론 vii쪽 |
| G4 | 판정은 **해당 대분류 안에서** 한다. 폭행은 신체학대 섹션에서, 폭언·협박은 정서학대 섹션에서 판단한다. | 우리 분류 정의 |
| G5 | 아동 본인이 **직접 부인**한 요소(대가·유포·접촉 등)는 근거가 될 수 없다. | G1의 적용 |
| G6 | 판단이 갈리는 경우는 `may`(허용)로 두고 억지로 하나로 정하지 않는다. | 우리 방침 |

## 신체학대

| 세부유형 | 해당하는 행위 | 근거 |
|---|---|---|
| 직접 신체 가해 | 손·발로 때림·참·꼬집음·조름, 머리채·머리카락을 잡음, 도구로 때리는 경우에도 해당 | 목차 Ⅰ-7, Ⅰ-8, 2부 Ⅰ-5 |
| 도구·위험수단 사용 | 막대기·벨트·효자손·쇠집게·줄넘기·흉기 등으로 가해, 수면제를 먹임 | 목차 Ⅰ-3, Ⅰ-6, Ⅰ-8 |
| 신체적 강압·제압 | 붙잡음·눌러 못 움직이게 함·끌고 감·묶음, 강제로 시킴 | 목차 Ⅰ-9, 2부 Ⅰ-5 |

밀침은 '직접 신체 가해'와 '신체적 강압·제압'에 **모두** 해당한다(팀 결정).

제외: 합리적 훈육 범위의 지도(G2). 신체적 학대가 있을 때 폭언은 정서학대 섹션에서 따로 본다(G3).

## 정서학대

| 세부유형 | 해당하는 행위 | 근거 |
|---|---|---|
| 폭언·모욕 | 욕설, "바보" 같은 인격 비하, 혐오성 발언, 외모·신체 비하, 아동 가족을 모욕하는 말을 듣게 함 | 목차 Ⅱ-5, Ⅱ-11, 2부 Ⅱ-6, Ⅱ-26·27, 일반론 xi쪽 |
| 위협·공포 유발 | "죽여버린다"·"칼로 자르겠다" 같은 해악 고지, 칼을 고르는 시늉, 공포·불안을 주는 문자, "다 부숴버린다" 협박, 집에서 내쫓겠다는 위협 | 목차 Ⅰ-7, Ⅱ-16~19, 2부 Ⅱ-4, Ⅱ-30 |
| 통제·강요·고립 | 강제로 술을 마시게 함·따르게 함, 억지로 먹게 함, 강제로 재움, 집 밖으로 내보내 못 들어오게 함, 방·화장실·베란다에 **못 나오게** 가둠, 친구와 놀지 못하게 함·따돌리게 함, 시간 등을 정해 강요 | 목차 Ⅱ-4, Ⅱ-9, Ⅱ-14, Ⅱ-15, Ⅱ-20, Ⅱ-22, 2부 Ⅱ-1, Ⅱ-7~9, Ⅱ-16, Ⅱ-19, Ⅱ-28 |
| 가정폭력·폭력상황 노출 | 부모 간 폭행·부부싸움을 목격하게 함, 자살 소동·흉기 소동을 보게 함, 반려동물 학대·약물 투약을 보게 함, 형제가 맞는 것을 보게 함 | 목차 Ⅱ-1~3, Ⅱ-6~8, Ⅱ-21, 일반론 vii쪽 |

제외: 아동 본인이 폭행을 당한 것은 신체학대(G4). 부모가 아동을 **무시·무관심**하는 것만으로는 위 네 유형 중 어디에도 해당하지 않는다(우리 분류에 해당 항목 없음, 판례집에서도 별도 유형으로 다루지 않음).
`위협` 말만 있고 실제 행동 제한이 없으면 통제·강요·고립은 선택하지 않는다(우리 분류 정의). 협박과 통제가 각각 별개의 행위로 있으면 둘 다 선택한다(목차 Ⅱ-15: "손가락 잘라버린다"며 못 들어오게 함, Ⅱ-22: 도깨비 앱을 켜고 화장실에서 못 나오게 함).

## 성학대

성적 학대는 신체 접촉이 없어도 성립한다(일반론 viii쪽).
아동이 동의했더라도 성적 학대에서 제외되지 않는다(일반론 viii쪽, 2부 Ⅲ-11~13).

| 세부유형 | 해당하는 행위 | 근거 |
|---|---|---|
| 성적 노출·성희롱 | 성적 발언·성희롱, 성관계 경험을 물음, 자위행위를 보임, 음란 영상·문자를 보냄, 신체 사진·영상을 보내라고 요구(온라인 포함), 옷을 벗으라고 시킴 | 2부 Ⅲ-1, Ⅲ-3, Ⅲ-10, 일반론 viii쪽 |
| 성적 접촉·추행 | 허벅지·가슴·성기·엉덩이 등을 만짐, 옷·속옷을 벗김, 몸을 누르거나 끌어안음, 입맞춤 | 2부 Ⅲ-2, Ⅲ-4, 일반론 viii쪽 |
| 성교·유사성행위 | 성기 결합, 구강성교, 손가락·물건 삽입, 동의가 있어도 해당 | 2부 Ⅲ-11~13, 일반론 viii쪽 |
| 성적 착취 | 성매수·성매매 권유, 대가를 조건으로 한 성적 행위, 이미 보낸 사진·영상을 유포하겠다는 협박 | 2부 Ⅲ-6~9 (대가·성매수), 우리 분류 정의(유포 협박) |

제외: 삽입 없이 시도만 했거나 '하려다 못했다'는 성교가 아니라 접촉·추행으로 본다(우리 분류 정의).
접촉 중 별개의 비접촉 행위(노출 등)가 따로 진술되면 노출·성희롱도 함께 선택한다(G3).
대가나 유포를 아동이 직접 부인한 경우 성적 착취가 아니다(G5).

## 방임 (유기 포함, 우리 분류는 3종)

| 세부유형 | 해당하는 행위 | 근거 |
|---|---|---|
| 기본적 보호·양육 방임 | 식사·의복·위생·안전·감독 부족, **유기**(버리고 떠남, 두고 감, 베이비박스), 영유아를 혼자 방치, 장기간 혼자 살게 함, 불결한 환경 방치, 다른 보호자의 학대를 제지하지 않음 | 목차 Ⅲ-1~5, Ⅲ-9, Ⅲ-14, Ⅲ-15, 일반론 viii~ix쪽 |
| 교육적 방임 | **아동 본인**을 정당한 사유 없이 등교시키지 않음, 무단결석 허용·미지도, 의무교육 이수 거부, 고의적·반복적으로 교육 기회를 박탈 | 목차 Ⅲ-6, Ⅲ-7, Ⅲ-11, 일반론 ix쪽 |
| 의료적 방임 | 아픈 아동을 병원에 데려가지 않음, 필수 예방접종을 하지 않음, 병원비를 주지 않음 | 목차 Ⅲ-8, Ⅲ-10, 일반론 viii~ix쪽 |

제외: 출생신고를 하지 않은 것만으로는 방임이 아니다(필수 예방접종 등 기본 서비스를 못 받게 한 경우에만 해당, 일반론 ix쪽).
학교 **행사**(참관수업·학부모 상담)에 부모가 오지 않은 것은 교육적 방임이 아니다(우리 분류 정의: 아동 본인의 결석·미취학이어야 함).
