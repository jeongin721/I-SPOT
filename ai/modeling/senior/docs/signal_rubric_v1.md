# 어르신 정서 · 위기 신호 기준표 v1 (초안)

1 · 2단계 화면(기록 확인 · 정서 · 위기 신호 확인)에서 AI 가 신호를 붙이고 1~5 '우려 정도' 를 **제안** 할 때,
그리고 담당자가 그 제안을 고칠 때 함께 보는 기준이다. 아동 `abuse/docs/subtype_rubric_v1.md`(판례집 기반 14종)와
같은 틀로 만들었다.

**이 문서는 현장 · 전문가 검수를 거치지 않은 초안이다(2026-11-17).** 근거 열에 '우리 분류 정의' 라고 적은 곳은 공식 자료에
그대로 있는 기준이 아니라 우리가 정한 것이다. 공식 자료 이름은 「온담 돌봄관리 플랫폼 — 웹에 넣을 법령·정책·매뉴얼」
(2026-11-16)의 목록을 따랐고, **쪽 · 조문 위치는 원문을 받은 뒤 채운다**(지금은 '원문 대조 필요').

## 0. 이 기준표가 하는 일과 하지 않는 일

| 한다 | 하지 않는다 |
|---|---|
| 어르신이 **말씀하신 내용** 가운데 담당자가 다시 확인해야 할 것을 신호별로 묶는다 | 우울증 · 치매 · 질병이 있는지 판단하거나 가능성을 점수로 낸다 |
| '우려 정도' = **담당자가 얼마나 서둘러, 무엇을 확인해야 하는가** 를 1~5로 제안한다 | 치료 · 약 조절 · 진료를 권한다 |
| 신호마다 확인 서식 · 연계처(고정 연락처)를 안내한다 | 목소리 톤 · 떨림 · 크기 · 말 속도로 상태를 추정한다 |
| 앞 회차에 담당자가 확정한 단계와 견줘 '달라짐' 을 보인다 | 학대 · 위기 여부를 확정하거나 조치를 자동으로 정한다 |

근거: 의료법 제27조(의료인 아닌 사람의 의료행위 금지), 식약처 「생성형 인공지능 의료기기 허가·심사 가이드라인」(2025.1
— 음성을 분석해 질병 징후를 찾는 기능은 의료기기에 해당할 수 있음), 멘토 기준 'AI 는 진단하지 않고 담당자의 판단을 돕는다'.
화면 아래에는 늘 "이 결과는 진단이 아니며, 판단은 담당자가 합니다" 를 둔다.

## 1. 공통 원칙

| # | 원칙 | 근거 |
|---|---|---|
| P1 | 어르신이 **직접 구체적으로 말씀한 내용** 만 근거로 삼는다. 담당자 질문에 "응" · "그렇지" 만 답한 것은 무엇을 인정했는지 특정되지 않으므로 근거가 아니다. | 아동 기준표 G1 과 같은 원칙 |
| P2 | **가족 · 동석자 말** 은 '가족 진술' 로 따로 표시하고, 단계를 매길 때는 어르신 말씀과 섞지 않는다. 가족 말만 있으면 단계를 비우고 "어르신께 직접 확인" 을 안내한다. | 우리 분류 정의 |
| P3 | 단계는 말씀 속 **무엇 · 얼마나 오래 · 일상에 얼마나 영향 · 도와주는 사람이 있는지** 로만 매긴다. 목소리 · 표정 · 말투는 쓰지 않는다. | 0절 근거 |
| P4 | 판단할 정보가 모자라면 억지로 매기지 않고 **단계를 비운다**(화면: '— 확인 후 판단'). 확인할 질문을 대신 낸다. | 아동 severity_llm 정보 부족 처리와 같음 |
| P5 | 한 신호에 근거가 여럿이면 **가장 높은 것** 으로 매긴다. 가벼운 말이 섞였다고 낮추지 않는다. | 아동 severity_llm 과 같음 |
| P6 | 한 말씀이 여러 신호에 해당할 수 있다(예: "입맛이 없고 잠도 못 자" → 식사 · 수면). 신호마다 따로 근거를 단다. | 아동 기준표 G3 과 같은 원칙 |
| P7 | **자살 생각 · 학대 의심 · 급한 건강 문제** 는 단계와 상관없이 말씀이 있으면 화면 맨 위에 안내 카드(고정 연락처)를 띄운다. 다음 방문으로 넘기지 않는다. | 법령·매뉴얼 문서 '위기·연계 기준' |
| P8 | 앞 회차와 견줄 때는 **담당자가 확정한 단계** 끼리만 견준다(AI 제안끼리 견주지 않는다). 화면은 '7회차 관심 → 상승' 처럼 사실만 보인다. | 영역 변화(care_domains)와 같은 원칙 |
| P9 | AI 제안과 담당자가 고친 단계를 둘 다 남긴다(누가 · 언제 · 왜 고쳤는지 메모). | 인공지능기본법(AI 결과물 표시), 아동 2단계와 같음 |

## 2. 단계의 공통 뜻 (모든 신호)

| 단계 | 공통 뜻 | 담당자에게 주는 안내 |
|---|---|---|
| 1 | 한 번 스치듯 말씀하심. 일상에 영향이 드러나지 않음 | 기록만, 다음 방문에 가볍게 여쭤 봄 |
| 2 | 최근 일로 말씀하심. 일상 영향은 적고 스스로 대처하고 계심 | 다음 방문 확인사항에 올림 |
| 3 | **이어지고 있다**(몇 주 이상)고 하시거나 일상 일부에 영향(끼니 거름 · 외출 줄임 등) | 이번 회차 안에 확인 서식 작성 · 연계 검토 |
| 4 | 일상 대부분에 영향이 있거나, 빠르게 달라졌다고 하시거나, 도와줄 사람 없이 혼자 감당하고 계심 | 담당 전담사회복지사와 공유, 연계처 안내, 재방문 · 전화 일정을 앞당김 |
| 5 | **지금 어르신 안전이 걱정되는 말씀**(신호별 정의 참고) | 방문 중 바로 확인, 고정 연락처 안내 카드, 기관 보고 절차 |

'몇 주 이상' · '일상 대부분' 같은 경계는 우리 분류 정의다. 현장 검수 때 숫자(예: 2주)로 정할지 정한다.

## 3. 신호별 기준

신호 이름은 화면에 보이는 이름이고, 괄호 안은 코드에서 쓰는 키다. '영역' 은 생활 · 정서 영역 변화(5단계 · care_domains)에서 같이 보는 영역이다.

### 3-1. 우울감 (`LOW_MOOD`) — 영역: 정서

기분이 가라앉음, 즐겁던 일에 흥미가 줄어듦, 살맛이 없다는 말씀. **우울증 여부는 판단하지 않는다.**

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | "오늘은 좀 울적하네" 처럼 그날 기분만 한 번 말씀 |
| 2 | 최근 기분이 가라앉았다고 하시지만 하시던 일(경로당 · 텃밭 등)은 그대로 하심 |
| 3 | 가라앉은 기분이 **이어진다** 고 하시거나, 좋아하던 일을 요즘 안 하신다고 하심("복지관은 요새 통 못 나갔어") |
| 4 | 하루 대부분을 누워 지내신다 · 아무것도 하기 싫다 · 사는 재미가 하나도 없다고 하시며 식사 · 수면 등 다른 신호가 함께 있음 |
| 5 | 우울감 말씀에 **자살 생각** 이 함께 나옴 → 3-2 자살 생각 기준으로 올려 본다 |

확인 서식: **S-03** 우울감 확인(단축형 노인우울척도 SGDS-K 를 담당자가 선별 확인 — **선별 결과이며 진단이 아님**).
연계처: 지역 정신건강복지센터. 근거: 정신건강복지법, 노인맞춤돌봄 사업안내(우울 관련 특화서비스 — 원문 대조 필요).
쓰지 않는 말: 우울증 · 우울장애 · 우울 의심 · 치료 필요.

### 3-2. 자살 생각 (`SUICIDAL`) — 영역: 정서 · 안전 발화 SELF_HARM 과 같음

죽고 싶다 · 살기 싫다 · 없어지고 싶다 · 스스로 해치려는 생각이나 준비에 대한 말씀. **말씀이 있으면 P7 안내 카드를 늘 띄운다.**

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | (쓰지 않음 — 자살 관련 말씀은 2단계부터) |
| 2 | "이렇게 살아서 뭐 하나" 처럼 삶의 의미가 없다는 말씀. 죽음 · 자해를 직접 말씀하지는 않음 |
| 3 | "죽고 싶다는 생각이 든다" 처럼 생각을 직접 말씀. 방법 · 계획은 말씀 안 하심 |
| 4 | 생각이 자주 든다고 하시거나, 예전에 시도한 적이 있다고 하심 |
| 5 | 방법 · 시기 · 준비(약을 모아 둠 등)를 말씀하시거나, 오늘 · 곧 하겠다는 말씀 |

**화자 · 근거가 확인되기 전에는 단계를 매기지 않는다**(P2 · P4). 화면: "화자 · 근거 확인 전이라 단계를 매기지 않았어요 · 먼저 확인해 주세요".
확인 서식: **S-04** 자살 위기 확인(기관 위기 대응 절차). 연락처(고정): 자살예방상담 **109**, 정신건강위기상담 **1577-0199**, 긴급 **119 · 112**.
근거: 자살예방 및 생명존중문화 조성을 위한 법률, 정신건강복지법. 예전 번호 1393 은 쓰지 않는다(2024.1 부터 109 로 통합).

### 3-3. 외로움 · 고립 (`ISOLATION`) — 영역: 사회활동 · 외출

만나는 사람 · 연락 · 바깥 활동이 줄었거나 끊겼다는 말씀.

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 가끔 적적하다고 하심. 연락 · 만남은 이어지고 있음 |
| 2 | 외롭다고 하시고 만남이 전보다 줄었다고 하심 |
| 3 | 가족 · 이웃 연락이 드물다(먼저 해야 받는다 등)고 하시거나 외출 · 모임을 거의 안 하신다고 하심 |
| 4 | 며칠씩 아무와도 이야기하지 않는다 · 찾아오는 사람이 없다고 하심, 혼자 사시며 응급 시 연락할 사람이 없다고 하심 |
| 5 | 고립과 함께 3-2 자살 생각 · 3-7 건강 급변 말씀이 있음 → 그 신호 기준으로 올려 본다 |

확인 서식: **S-05** 사회관계 · 고립 확인(고독사 위험 확인 도구 사용 여부는 원문 대조 필요). 혼자 사시면 **응급안전안심서비스 이용 여부** 를 확인한다.
연계처: 노인맞춤돌봄 사회참여 서비스, 응급안전안심서비스. 근거: 고독사예방법, 2026 고독·고립 예방 및 관리 사업 운영 지침, 2026 응급안전안심서비스 사업안내.

### 3-4. 식사 · 영양 변화 (`MEAL`) — 영역: 식사

끼니를 거름, 입맛이 없음, 장보기 · 조리가 어려움.

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 입맛이 좀 없다고 한 번 말씀 |
| 2 | 끼니를 가끔 거르신다고 하심 |
| 3 | 하루 한 끼만 드신다 · 입맛 없는 게 이어진다고 하심, 혼자 먹기 싫어 거르신다고 하심 |
| 4 | 며칠째 거의 못 드신다고 하시거나, 장보기 · 조리를 할 수 없어 드실 게 없다고 하심 |
| 5 | 물도 잘 못 드신다 · 며칠 굶었다고 하심(안전 발화 URGENT_HEALTH 와 같음) |

확인 서식: **S-02** 식사 · 수면 변화 확인(욕구 · 자원 사정에 기록, 맞춤돌봄 식사 지원 연계 검토). 체중 측정값이 있으면 지난번과의 차이만 함께 보인다(정상 · 위험 기준 없음).
근거: 노인맞춤돌봄 사업안내(일상생활 지원 — 원문 대조 필요).

### 3-5. 수면 변화 (`SLEEP`) — 영역: 수면

잠들기 어려움, 자주 깸, 너무 많이 잠.

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 어젯밤 잠을 설쳤다고 한 번 말씀 |
| 2 | 요즘 밤에 한두 번 깬다고 하심 |
| 3 | 새벽에 깨면 다시 못 주무신다는 게 이어진다고 하시거나, 낮에도 자꾸 누워 계신다고 하심 |
| 4 | 거의 못 주무신다고 하시며 낮 생활(식사 · 외출)에 영향이 있다고 하심 |
| 5 | (단독으로는 쓰지 않음 — 함께 나온 다른 신호 기준으로 본다) |

확인 서식: **S-02**(식사와 같은 서식). 수면제 등 약 이야기는 그대로 옮기되 조절을 권하지 않는다.

### 3-6. 기억 · 일상 수행 변화 (`MEMORY_DAILY`) — 영역: 정서 · 외출

깜빡함, 약 드신 걸 잊음, 같은 말 반복, 길을 잃음, 가스불 · 문단속을 잊음. **치매 여부는 판단하지 않는다.**

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 요즘 깜빡깜빡한다고 한 번 말씀 |
| 2 | 물건 둔 곳 · 약속을 자주 잊으신다고 하심 |
| 3 | 약 드신 걸 잊어 두 번 드시거나 거르신다고 하심, 같은 이야기를 반복하신다(가족 진술은 P2) |
| 4 | 익숙한 길에서 헤매셨다 · 가스불을 켜 두고 잊으셨다처럼 안전과 이어진 일이 있었다고 하심 |
| 5 | 집을 찾지 못해 다른 사람 도움으로 돌아오셨다 · 불이 날 뻔했다 같은 일이 최근 있었다고 하심 |

확인 서식: **S-06** 기억 · 일상 변화 기록(치매안심센터 조기검진 연계 검토). 복약 관련은 프로필의 복약 정보와 함께 확인한다.
연계처: 치매안심센터(보건소). 근거: 치매관리법, 2026 치매정책 사업안내, 제5차 치매관리종합계획(2026~2030, 다른 복지사업 대상자의 치매검진 연계 강화).
쓰지 않는 말: 치매 · 인지장애 · 치매 의심 · 경도인지장애.

### 3-7. 건강 급변 · 신체 불편 (`HEALTH_CHANGE`) — 안전 발화 URGENT_HEALTH 와 같음

통증, 낙상, 숨참, 쓰러짐, 측정값 변화에 대한 말씀. **병명을 붙이지 않는다.**

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 무릎 · 허리가 쑤신다처럼 늘 있던 불편을 말씀 |
| 2 | 최근 새로 불편한 곳이 생겼다고 하심 |
| 3 | 넘어지셨다(다치지 않음) · 불편 때문에 외출 · 집안일을 줄이셨다고 하심, 카라반 측정값이 지난번과 크게 다름(정상 · 위험 판단 없이 차이만) |
| 4 | 넘어져 다치셨다 · 통증이 심해 잠을 못 주무신다고 하심 |
| 5 | 가슴 통증 · 숨참 · 쓰러짐 · 한쪽 마비 · 말이 어눌해짐을 **지금 또는 오늘** 겪고 계시다고 하심 → 119 |

확인 서식: **S-07** 건강 상태 변화 기록(보건소 방문건강관리 연계 검토). 화면 문구는 "지난 측정보다 높음", "카라반 안내: 재측정 권장" 처럼 값의 변화와 안내만.
근거: 국가건강검진 검진의사 상담매뉴얼(2025, 검진 뒤 상담에서 확인할 생활습관), 보건소 방문건강관리 안내.

### 3-8. 학대 · 방임 의심 말씀 (`ABUSE_CONCERN`)

가족 · 돌보는 사람 · 다른 사람에게 맞음 · 욕설 · 돈을 빼앗김 · 방치됨, 또는 스스로를 돌보지 못함(자기방임)에 대한 말씀.
**학대 여부는 판정하지 않는다.** 말씀이 있으면 P7 안내 카드를 띄운다.

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | (쓰지 않음 — 2단계부터) |
| 2 | 가족과 다툼 · 서운함을 말씀. 해를 입었다는 말씀은 없음 |
| 3 | 욕을 듣는다 · 무시당한다 · 연금 · 통장을 가족이 가져가 쓴다고 하심 |
| 4 | 맞았다 · 밀쳤다 · 밥을 안 준다 · 집에 혼자 두고 오지 않는다고 하심 |
| 5 | 지금도 같이 살며 계속 그렇다 · 무섭다 · 다칠까 걱정된다고 하심 |

확인 서식: **S-08** 학대 의심 기록(기관 신고 절차 — 생활지원사 · 전담사회복지사가 신고의무자인지는 수행기관 유형에 따라 달라 대표님 측과 확인 필요, "누구나 신고할 수 있다" 는 늘 안내).
연락처(고정): 노인보호전문기관 **1577-1389**, 수사기관 **112**. 근거: 노인복지법 제39조의6(원문 대조 필요). 신고자 신분은 보호된다.
쓰지 않는 말: 학대 확정 · 가해자 · 피해자 · 범죄(아동과 같은 question_rules 판정 표현 검사를 쓴다).

### 3-9. 생계 · 생활 어려움 (`LIVELIHOOD`)

생활비 · 집세 · 공과금 · 병원비가 갑자기 어려워졌다는 말씀.

| 단계 | 해당하는 말씀 (예) |
|---|---|
| 1 | 살림이 빠듯하다고 한 번 말씀 |
| 2 | 병원비 · 약값이 부담된다고 하심 |
| 3 | 공과금이 밀렸다 · 끼니를 줄여 아끼신다고 하심 |
| 4 | 집세 · 난방비를 못 내 집을 비워야 할 수 있다고 하심 |
| 5 | 당장 드실 것 · 난방이 없다고 하심 |

확인 서식: **S-09** 생활 어려움 확인(긴급복지 · 통합돌봄 안내). 연락처(고정): 보건복지상담센터 **129**, 행정복지센터.
근거: 긴급복지지원법, 돌봄통합지원법(2026.3.27 시행, 통합돌봄 신청은 행정복지센터 · 건강보험공단 지사).

## 5. 회차 전체 '위기도 제안' (위기 · 집중 · 관심 · 일반) — 멘토 확인 전에는 쓰지 않는다

디자인 2단계 맨 위 카드다. 지금까지 고령자에는 위기도를 두지 않기로 했으므로(멘토 기준 'AI 는 진단하지 않음'),
**아래 규칙은 멘토 확인을 받은 뒤에만 켠다.** 켜더라도 AI 는 '제안' 만 하고 담당자가 고른다.

| 제안 | 규칙(확정된 · 제안된 신호 단계로 계산, LLM 이 정하지 않음) |
|---|---|
| 위기 | 3-2 자살 생각 4 이상, 또는 3-8 학대 의심 5, 또는 3-7 건강 급변 5 |
| 집중 | 위기가 아니면서 어느 신호든 4 이상, 또는 3 이상인 신호가 둘 이상 |
| 관심 | 어느 신호든 3, 또는 앞 회차보다 한 단계 이상 오른 신호가 있음 |
| 일반 | 그 밖 |

위기도는 신호 단계에서 **계산** 한다(LLM 이 따로 매기지 않는다) — 같은 입력이면 늘 같은 답이 나오게.

## 6. LLM 출력 모양 (구현 때)

```jsonc
{
  "signals": [
    {
      "signal": "LOW_MOOD",                // 3절 키
      "level": 3,                           // 1~5 또는 null(P4 정보 부족)
      "criterion": "가라앉은 기분이 이어진다고 하시거나 좋아하던 일을 요즘 안 하심",  // 해당 단계 기준 문장(이 표에서 그대로)
      "segment_ids": ["s12", "s3"],         // 어르신 발화만(P1). 가족 발화는 family_segment_ids
      "family_segment_ids": [],
      "reason": "복지관을 요새 못 나갔다고 하심(s3)"   // 판정 · 진단 말 금지
    }
  ]
}
```

검사(아동 템플릿과 같은 방식): 근거 발화가 없거나 담당자 발화만 있으면 버림, `criterion` 은 이 표의 문장과 같아야 함,
진단 · 판정 말(senior_brief_llm.FORBIDDEN, question_rules.judgment_reason)이 있으면 버림, 3-2 · 3-8 은 2단계 미만으로 내지 않음.
1차 임시 스캔(1단계 화면)은 LLM 없이 낱말 규칙(senior_session_llm.SAFETY_PATTERNS, care_domains.DOMAIN_PATTERNS)으로 한다.

## 8. 검수 때 정할 것

1. 2절 '몇 주 이상' · '일상 대부분' 을 숫자로 정할지.
